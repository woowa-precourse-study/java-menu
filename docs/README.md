추천할 카테고리 랜덤 정함
각 코치가 먹을 메뉴 추천



- [x] 코치의 이름은 최소 2글자, 최대 4글자이다.

- [x] 코치는 최소 2명, 최대 5명까지 식사를 함께 한다.

- [x] 각 코치는 최소 0개, 최대 2개의 못 먹는 메뉴가 있다.
  (, 로 구분해서 입력한다. 먹지 못하는 메뉴가 없으면 빈 값을 입력한다.)

- [ ] 한 주에 같은 카테고리는 최대 2회까지만 고를 수 있다.
- [ ] 각 코치에게 한 주에 중복되지 않는 메뉴를 추천해야 한다 



에러 메세지

- [x] 코치 이름은 최소 2글자, 최대 4글자여야 합니다.
- [x] 코치는 최소 2명 이상 입력해야 합니다.
- [x] 코치는 최대 5명 이하 입력해야 합니다.
- [x] 코치 이름은 중복될 수 없습니다.

- [x] 못 먹는 음식은 2개 이하 입력해야 합니다.
